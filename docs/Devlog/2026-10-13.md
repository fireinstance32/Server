# 2026-10-13

- **Pivot: +1 Frog Hop → rock lifting.** Same Stone Skipping loop: lift your rock for Strength, throw it down the field for Wins. Pets, eggs, rebirth, potions, the Shop and all the UI stay. Plan, naming table and stages in [[Rock Pivot]].
- **Stage 1 – words:** every on-screen Hops / Frog / Pond / Hop / River string changed: Hops → **Strength**, frogs → **rocks** (Pebble, Mossy Stone, Clay Rock … Meteorite, Phoenix Stone; world rocks like Moon Rock, Magma Rock, Rock Candy), ponds → **gyms** (Starter, Iron, Crystal, Royal, Golden, Rainbow, Cosmic), HOP button → **THROW**, Auto Hop → **Auto Lift**, Hop Zone → **Throw Zone**, Lily Valley → **Stone Valley**, frog-named pets / titles / codes (codes now WELCOME, STRONG, ROCKON). Potion chips read their stat through `Potions.StatWord`. Code names (`data.hops`, `HopService`, `Config/Frogs`, `Ponds`) are unchanged so saves keep working.
- **Stage 2 – gameplay (first pass):** frogs are now rocks in code too: `Models.rock` (new `Models/Rock.luau`: a few rotated blocks make a faceted rock, same shape per rock id; glowing rocks get neon flecks and a light). It's used for the held rock, the thrown rock (it tumbles in flight), podiums and the Rocks tab. Gym training is now a lift rep (`LiftAnimation`: the arm presses the rock overhead, +Strength pops at the top) instead of a frog hopping pads. Rock colours changed to stone colours; Bullfrog → Boulder. Not tested in Studio yet (Studio wasn't connected).
- **Title:** *+1 Lift Rock For Pets*.
- **Prices:** one middle ladder for every Robux item — small 19–59, most passes/packs 79–129, big 199–449 (was a mix of 5 to 540 copied from the reference). Full list in [[Monetization Setup]] (rewritten with the new names and every Shop product).
- **Starter Pack:** 49 (was 249), now with an exclusive pet, the **Rainbow Unicat** (Legendary, ×25: cat + unicorn horn + rainbow mane + neon rainbow feather wings, its own face `face_unicat.png`). The HUD Starter Pack is now a picture put together in code like the reference: Strength potion, bolt and rebirth icons fanned behind the Unicat, a slow golden sunburst, idle bob; hidden once bought. `pets.png` re-rendered (45 pets) and re-uploaded (new id in `UiImages`).
- **Lift / toss fix:** your avatar uses Roblox's upgraded joints (the shoulder is an `AnimationConstraint`, not a `Motor6D`), so the procedural arm moves did nothing. New `Controllers/Shoulder.luau` adds the arm angle on top of the Animator every frame on either joint type; tested in Studio: the hand goes from waist to over the head each lift.
- Next: stage 3 (rock icon, frogs.png picture sheet → rock pictures), stage 4 (Blender rocks, gyms, the field map, real lift/throw animations).

# +1 Stone Skipping (reference)

- Developer: Meow Labs. Created ~2026-09-05, 12.5M+ visits, reported peak ~75K CCU.
- Loop: Throw button → stone skips; **each bounce +1 Skill**; distance → zone → **Wins**.
- Training at small ponds (incl. AFK auto-train areas); river throws pay Wins.
- 5 worlds, each ~9 territories + portal. World 2 gate ≈ 100M Skill.
- World 1 stones: Pebble (free), Scallop Shell 2, Ammonite 10, Starfish 40, Wood Slice 150, Roof Tile 500, Bottle Cap 1.5K, Lucky Coin 4.5K, Hockey Puck 14K, Frisbee 40K. Phoenix Relic 199 R$.
- Eggs: Common 50 Wins (W1); Epic 100K, Legendary 2.5M, Mythical 75M (W2); Pirate egg Robux-only.
- Potions: Skill, Wins, Luck (stackable, timed).
- Rebirth unlocks better auto-training zones.
- Shop: ~4 pages of dev products (see [[Monetization]]).
